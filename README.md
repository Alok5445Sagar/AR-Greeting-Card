# 📖 Overview

The **AR Greeting Card** project is an interactive Augmented Reality application developed using **Unity 3D** and **Vuforia Engine**. The application enhances traditional greeting cards by overlaying digital content such as:
- 🎥 Videos
- 🎵 Audio
- 🎨 3D animations
- 💌 Interactive messages
- ✨ Visual effects

Using marker-based AR tracking, users can scan a greeting card with their mobile device and instantly experience immersive multimedia content in real time.

The project demonstrates:
- Augmented Reality visualization
- Interactive multimedia systems
- Marker-based tracking
- Real-time rendering
- Creative AR experiences

```text
                ↓
3D Animations & Multimedia Activated
                ↓
Interactive AR Experience Displayed
```

---

# 📸 How It Works

1. The user opens the AR Greeting Card application.
2. The mobile camera scans the greeting card image target.
3. Vuforia detects and tracks the marker in real time.
4. Multimedia content such as videos, animations, and audio is triggered.
5. Users experience an immersive interactive greeting card in AR.

# 🚀 Installation

## Clone the Repository

```bash
git clone https://github.com/Alok5445Sagar/AR-Greeting-Card.git
```

## Open in Unity

1. Open Unity Hub
2. Add the project folder
3. Open using a compatible Unity version

## Configure Vuforia

- Enable Vuforia Engine
- Import image target database
- Configure AR camera settings

## Run the Application

- Connect Android device
- Build APK
- Launch the AR application
